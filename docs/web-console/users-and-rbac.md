# Users and role-based access

ThinRemote supports multi-user organizations with role-based permissions, so teams, partners, or customers can access only the devices they're entitled to.

## CLI-side tools

- Profiles for multi-account and multi-environment setups.
- Admin impersonation: the `-u/--user` global flag acts on behalf of another user (requires admin).
