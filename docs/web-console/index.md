# Web Console

The Web Console is the browser-based UI for managing devices, products, users, dashboards, and alarms. It covers everything the CLI exposes, plus the visual tools (remote desktop, filesystem explorer, metric dashboards).

## Planned content

- URL and sign-in flow
- Navigation overview (devices, products, users, settings)
- Device view: status, metrics, sessions, files, scripts
- Dashboards and alarms
- Role management
