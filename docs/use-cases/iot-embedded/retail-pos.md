# Retail POS terminals

Point-of-sale terminals span many stores with heterogeneous connectivity. Support engineers need a single pane of glass and no VPN juggling.

## What ThinRemote gives you

- One-agent-per-store (or per-terminal) with centralized inventory.
- Remote desktop for graphical POS applications.
- Scripted software updates fleet-wide.
