# Edge gateways

Edge gateways aggregate sensor data, run local logic (Node-RED, ML inference, custom pipelines), and forward to the cloud. They need remote lifecycle management and dashboard access.

## What ThinRemote gives you

- HTTP tunneling to local dashboards (Node-RED editor, Grafana, Jupyter).
- Custom agent scripts to expose gateway-specific operations as remote resources.
- Monitoring + alarms on CPU/memory/disk for proactive maintenance.
