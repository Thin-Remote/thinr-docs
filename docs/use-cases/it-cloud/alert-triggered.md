# Alert-triggered instant access

Pairing ThinRemote with your alerting stack shortens incident response: when a metric or device alert fires, the on-call engineer has a one-click path to a secure session on the affected device.

## What ThinRemote gives you

- Device alerts tied to monitored metrics (CPU, memory, custom properties).
- Deep-link tunnels that spin up on demand.
