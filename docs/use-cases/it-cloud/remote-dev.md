# Remote dev and testing environments

Developers often need to target environments they don't have locally: ARM boards, GPU nodes, or isolated test benches. ThinRemote tunnels the relevant endpoints into your laptop.

## What ThinRemote gives you

- Terminal, TCP, TLS, and HTTP tunnels on demand.
- File transfer without SFTP gymnastics.
- Profiles to switch between staging and prod environments cleanly.
